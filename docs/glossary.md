# Glossary

| Word | What it means here |
|---|---|
| **Admin** | The person who manages ChessLoop. The account you made during the install. Admins see the **Admin panel**. |
| **Admin panel** | The gear-icon page where admins manage users, backups and system settings. |
| **Backup** | A copy of all your ChessLoop data in one file. [More](backup-restore.md). |
| **Container** | A sealed box that holds one part of ChessLoop, so nothing else on your computer changes. Docker runs them. |
| **Docker** | The program the installer adds to run ChessLoop in containers. |
| **Docker Desktop** | A Windows app that also provides Docker. You do not need it for ChessLoop. |
| **Install folder** | `/opt/chessloop`, where the installer puts ChessLoop's files. |
| **Leech** | A position you have answered wrongly four or more times. |
| **Library** | A set of opening lines you practise together, for example "Italian Game". |
| **Line** | One sequence of moves in a library. |
| **MFA** | Two-factor sign-in: a six-digit code from a phone app, as well as your password. |
| **Port** | The number after the colon in the address, such as `:8090`. |
| **PowerShell** | The Windows window where you type commands. |
| **Reverse proxy** | A program that adds HTTPS in front of a web service. Not covered here. |
| **Settings file** | `/opt/chessloop/chessloop/.env`. Holds ChessLoop's settings and secret key. [More](configuration.md). |
| **SMTP** | The way a program sends email through your mail provider. Only needed for email. |
| **Spaced repetition** | Reviewing things shortly before you would forget them. ChessLoop schedules this for you. |
| **sudo** | "Run this as the administrator." It asks for your own password. |
| **Terminal** | The window where you type commands on Linux. |
| **Ubuntu** | A popular version of Linux. |
| **WSL 2** | Windows Subsystem for Linux: a small Linux that runs inside Windows 11. |
